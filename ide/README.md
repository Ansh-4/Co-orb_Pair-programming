# Mini IDE

A simple desktop IDE built from scratch for writing, compiling, and running code.

## Features

* Code editor
* Create and open files
* Save files
* Run code
* Compile code
* View program output
* File explorer

## Tech Stack

* HTML
* CSS
* JavaScript
* Electron

## Project Structure

```text
mini-ide/
├── src/
│   ├── index.html
│   ├── style.css
│   └── script.js
├── main.js
├── package.json
└── README.md
```

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/mini-ide.git
```

### 2. Navigate to the project

```bash
cd mini-ide
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the IDE

```bash
npm start
```

## Goal

The goal of this project is to learn how an IDE works internally and build one from scratch while improving my understanding of JavaScript, Electron, file systems, processes, and code editors.
